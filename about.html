[ method ]

Methodology

A1

Impact over volume.

One account-takeover beats fifty low-severity headers. I chase the bugs that actually move risk — auth bypass, logic flaws, data exposure.

A2

Read the source.

Most logic bugs hide in code, not traffic. Static analysis with CodeQL and Semgrep does half the work before a single request goes out.

A3

AI is just another attack surface.

Prompt injection is the new injection; guardrails are the new WAF. I treat LLM features like any other untrusted boundary — and probe accordingly.

A4

Do automation, not dependency on it.

I design tooling to handle the repetitive layer — recon, payload generation, batching — so my focus stays on the logic problems that require actual thinking.
